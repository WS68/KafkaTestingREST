# KafkaTestingREST

## Назначение

KafkaTestingREST — вспомогательный сервис для тестирования асинхронных операций с Kafka. Он предоставляет тесту HTTP API, а сам сервис для публикации, чтения записей и управления собственными группами всегда напрямую подключается к нативному брокеру Kafka.

Сервис рассчитан на небольшую нагрузку — ориентировочно 10–50 запросов в секунду — и работу в одной реплике. Состояние слотов и накопленных записей хранится в памяти процесса и теряется при перезапуске. Развёртывание нескольких реплик не поддерживается.

## Основные требования

- Доступный кластер Kafka и адрес нативного брокера в формате `хост:порт`.
- Kafka REST API и REST-прокси для работы сервиса не требуются.
- Целевая технологическая основа: Node.js 22+, TypeScript и Fastify.
