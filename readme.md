# KafkaTestingREST

## Назначение

KafkaTestingREST — вспомогательный сервис для тестирования асинхронных операций с Kafka. Он позволяет тесту публиковать записи в Kafka через HTTP и наблюдать за записями, поступающими в топики, чтобы ожидать и проверять результаты работы тестируемой системы.

Сервис рассчитан на небольшую нагрузку — ориентировочно 10–50 запросов в секунду — и работу в одной реплике. Состояние слотов и накопленных записей хранится в памяти процесса и теряется при перезапуске. Развёртывание нескольких реплик не поддерживается.

## Основные требования

- Доступный кластер Kafka.
- Доступный Kafka REST API, используемый сервисом для публикации записей.
- Для сборки требуется среда и инструментарий, предусмотренные проектом; сведения о версии Java, файле сборки и командах сборки или запуска в текущем репозитории не указаны.

## Запуск и сборка

В репозитории не указаны команды сборки и запуска. Необходимые параметры подключения и остальные настройки сервиса описаны в документе [«Конфигурация»](docs/configuration.md).
