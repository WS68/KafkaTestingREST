# KafkaTestingREST

## Назначение

KafkaTestingREST — вспомогательный сервис для тестирования асинхронных операций с Kafka. Он предоставляет тесту HTTP API, а сам сервис для публикации, чтения записей и управления собственными группами всегда напрямую подключается к нативному брокеру Kafka.

Сервис рассчитан на небольшую нагрузку — ориентировочно 10–50 запросов в секунду — и работу в одной реплике. Состояние слотов и накопленных записей хранится в памяти процесса и теряется при перезапуске. Развёртывание нескольких реплик не поддерживается.

## Основные требования

- Доступный кластер Kafka и адрес нативного брокера в формате `хост:порт`.
- Kafka REST API и REST-прокси для работы сервиса не требуются.
- Node.js 22 или новее.

## Установка, запуск и проверки

Установите зависимости и соберите проект:

```sh
npm ci
npm run build
```

Запустите сервис командой `npm start`. Перед запуском задайте обязательную переменную `KAFKA_TESTING_REST_CLUSTER`; остальные переменные окружения кратко описаны в [документе конфигурации](docs/configuration.md).

Основные команды проекта:

- `npm test` — модульные и контрактные тесты.
- `npm run test:integration` — интеграционные тесты; адрес Kafka по умолчанию `localhost:9092` можно переопределить через `KAFKA_TESTING_REST_CLUSTER`.
- `npm run verify` — полный набор проверок проекта, включая проверку типов, форматирования, тесты, сборку и аудит зависимостей.
